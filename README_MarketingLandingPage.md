# 📣 Marketing Landing Page (GSAP Practice)

A simple and elegant landing page created to experiment with **GSAP** animations and scroll-based transitions.  
This project focuses on creating smooth frontend animations rather than full responsiveness.

## 🧠 Purpose

This project was built as part of my learning journey with **GSAP** (GreenSock Animation Platform) to strengthen frontend animation techniques.

## ✨ Features

- 🎯 Scroll-triggered **Hero and Feature sections**
- 🌀 Smooth transitions and timeline-based animations using **GSAP** and **ScrollTrigger**
- 🎨 Minimal UI structure for focused animation effects
- 💡 Great for animation prototyping and UI interaction testing

## 🛠️ Tech Stack

- **HTML5 / CSS3**
- **JavaScript (Vanilla)**
- **GSAP** & **ScrollTrigger**
